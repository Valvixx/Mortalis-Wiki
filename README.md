# Тёмный гримуар — вики поверх Obsidian-хранилища

Статичная вики без бэкенда: список и содержимое заметок движок берёт прямо
из вашего репозитория на GitHub через `api.github.com` и
`raw.githubusercontent.com`. Никакой сборки — просто кладёте `.md`-файлы
из Obsidian в папку `content/` и пушите.

## Как это устроено

- `index.html`, `css/style.css`, `js/app.js` — сам движок вики.
- `js/config.js` — единственное место, которое нужно настроить руками.
- `content/` — сюда копируются заметки из вашего хранилища Obsidian
  (можно с подпапками, они станут разделами в оглавлении).
- Ссылки `[[Название]]` и вставки `![[картинка.png]]` из Obsidian
  работают «из коробки».

Заметки читаются в момент открытия страницы в браузере пользователя —
никакого сервера, только статические файлы.

### Картинки

Картинки можно класть в любую папку, в том числе вложенную (например
`content/images/`, `content/Заклинания/images/` и так далее) — движок
сам находит файл по имени среди всего хранилища, путь в самой заметке
писать не обязательно, как и в Obsidian:

```
![[огненный-шар.png]]
```

Размер, заданный в Obsidian через `|`, тоже сохраняется:

```
![[огненный-шар.png|400]]        — ширина 400px, высота по пропорциям
![[огненный-шар.png|400x250]]    — ширина 400px, высота 250px
```

Обычный markdown-синтаксис `![alt](путь.png)` с локальным путём тоже
поддерживается — внешние ссылки (`http(s)://...`) не трогаются.

### Поиск

Поиск в боковой панели ищет не только по названиям заметок, но и по их
полному тексту. После открытия сайта движок в фоне подгружает содержимое
всех заметок для индекса — статус процесса виден внизу страницы. Пока
индексация не завершена, поиск по свежедобавленным словам может найти не
всё; для личной вики на десятки-сотни заметок это занимает несколько
секунд.

## Шаг 1. Создайте репозиторий на GitHub

1. Зайдите на [github.com](https://github.com) и нажмите **New repository**.
2. Дайте название, например `my-wiki`. Репозиторий может быть публичным
   (для приватного тоже можно включить Pages, но на платных тарифах).
3. Не добавляйте README/gitignore при создании — они уже есть в этом проекте.

## Шаг 2. Настройте `js/config.js`

Откройте `js/config.js` и впишите свои данные:

```js
window.WIKI_CONFIG = {
  owner: "ваш-ник-на-github",
  repo: "my-wiki",
  branch: "main",
  contentDir: "content",
  title: "Гримуар",
  homeNote: "Добро пожаловать",
};
```

## Шаг 3. Залейте файлы в репозиторий

Из папки проекта (там, где лежит `index.html`):

```bash
git init
git add .
git commit -m "Первая версия вики"
git branch -M main
git remote add origin https://github.com/ВАШ-НИК/my-wiki.git
git push -u origin main
```

Если раньше не работали с git — можно вместо этого просто перетащить все
файлы и папки в веб-интерфейс GitHub (кнопка **Add file → Upload files**
на странице репозитория), сохранив структуру папок.

## Шаг 4. Включите GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
3. Нажмите **Save**.
4. Через 1-2 минуты сайт появится по адресу:
   `https://ВАШ-НИК.github.io/my-wiki/`

GitHub Pages сам пересобирает сайт при каждом пуше в `main` — отдельно
ничего запускать не нужно.

## Шаг 5. Добавляйте свои заметки

1. Скопируйте `.md`-файлы (и картинки) из вашего хранилища Obsidian
   в папку `content/` этого репозитория — можно прямо с вложенными
   папками, как у вас в Obsidian.
2. `git add . && git commit -m "Новые заметки" && git push`
   (или через веб-интерфейс).
3. Обновите страницу сайта — новые заметки появятся в оглавлении и
   станут доступны по ссылкам `[[Название]]` из других заметок.

Заголовок в оглавлении и в адресной строке — это имя файла без `.md`,
как и в самом Obsidian.

## Ограничения, о которых стоит знать

- **GitHub API без авторизации** ограничен 60 запросами в час с одного
  IP — для чтения дерева файлов хватает одного запроса на загрузку
  страницы, так что для личного использования это не проблема.
- Работает только со **статьями из корня `content/`** — если нужно
  синхронизировать не всё хранилище, а только часть, копируйте вручную
  или настройте отдельную папку в Obsidian специально под вики.
- Для приватного хранилища GitHub Pages тоже подойдёт, если сделать
  репозиторий приватным (Pages на приватных репо доступны на GitHub Pro
  и организациях) — учтите, что `raw.githubusercontent.com` для
  приватных репозиториев потребует токен, текущий движок такое не умеет.
- Локально открыть `index.html` двойным кликом не получится (браузер
  блокирует fetch на `file://`). Для локальной проверки запустите
  простой сервер в папке проекта, например `python3 -m http.server`,
  и откройте `http://localhost:8000`.

## Что можно доработать дальше

- Тэги из front matter (`tags: [...]`) — сейчас просто игнорируются,
  можно вывести их под заголовком заметки.
- Граф связей между заметками.
- Кэширование через `localStorage`, чтобы не дёргать API при каждом
  открытии.
- Полнотекстовый поиск по содержимому, а не только по заголовкам.

Пишите, что поправить или добавить — стиль и структуру легко подстроить
дальше.
